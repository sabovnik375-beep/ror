01 /

Как это устроено

Три детали: код, таблица «код → ссылка» и страница-переходчик. Всё уже написано выше — вот что где лежит.

1

Генерация кода

Функция genCode() собирает случайные 6 символов: ab3x9K. Это ~56 миллиардов комбинаций — хватит на всю жизнь. Хочешь свой код — просто впиши его в поле «свой код».

2

Хранилище пар

В демо пара «код → ссылка» лежит в localStorage твоего браузера (функции load() / save()). Чтобы ссылки открывались у всех, замени их на запросы к бесплатной базе — например, Supabase:

// вместо load()/save() — таблица links(code, url, clicks) в Supabase (бесплатно)
const SUPA = 'https://xxxx.supabase.co';
const KEY  = 'твой anon key';

async function saveLink(item){
  await fetch(SUPA + '/rest/v1/links', {
    method: 'POST',
    headers: { apikey: KEY, Authorization: 'Bearer ' + KEY,
               'Content-Type': 'application/json' },
    body: JSON.stringify(item)
  });
}
3

Переход

Открываешь …/#ab3x → скрипт при загрузке находит код и делает location.replace(длинная ссылка). По пути считает клик. Вариант посерьёзнее — редирект на Cloudflare Workers (тоже бесплатно, без базы):

// worker.js — Cloudflare Workers
export default {
  async fetch(req, env) {
    const code = new URL(req.url).pathname.slice(1);
    const url  = await env.LINKS.get(code);  // KV-хранилище
    return url ? Response.redirect(url, 301)
               : new Response('Не найдено', { status: 404 });
  }
};

Создай репозиторий на GitHub → закинь туда index.html → Settings → Pages → Deploy. Через минуту страница живёт по адресу твойлогин.github.io — и это уже твоя ссылка. Бесплатно и навсегда.

Своя ссылка — свой домен

Чтобы сокращённые ссылки выглядели как korche.рф/promo, а не твойлогин.github.io/#promo, нужен короткий домен.

1

Купи короткий домен

У регистраторов (reg.ru, ru-center, Cloudflare, Namecheap). Зоны .site и .click бывают от ~100 ₽/год, .ru — около 200–300 ₽/год. Ищи короткое имя: korche, krch, tuda.

2

Привяжи его к хостингу

В настройках домена пропиши DNS-записи, которые покажет GitHub Pages / Netlify / Cloudflare. Подожди 5–30 минут — и твоя страница открывается по своему имени.

03 /

Вопросы

Ссылки будут работать у других людей?

В демо-режиме — нет: localStorage виден только твоему браузеру. Подключи Supabase или Cloudflare Workers (сниппеты в разделе «Как работает») — и ссылки откроются у кого угодно, с любого устройства.

Сколько это стоит?

Код, GitHub Pages, Supabase и Cloudflare Workers — бесплатно. Домен — по желанию, от ~100 ₽/год. Рекламы нет и не будет: это твоя страница.

Можно свои коды вместо случайных?

Да! Поле «свой код»: promo, skidka-20, cv. Ссылка станет читаемой: korche.рф/cv. Если код занят — страница ругнётся.

Зачем домен, если GitHub Pages и так даёт ссылку?

korche.рф/ab3x короче, красивее и вызывает больше доверия, чем username.github.io/#ab3x. Начни бесплатно на GitHub Pages, домен прикрутишь потом — код менять не придётся.
