Твои сокращения

01 /

Как это устроено

Три детали: код, таблица «код → ссылка» в твоей базе и страница-переходчик. Статус-чип в шапке показывает, жива ли связь с базой прямо сейчас.

1

Генерация кода

Функция genCode() собирает случайные 6 символов: ab3x9K. Это ~56 миллиардов комбинаций — хватит на всю жизнь. Хочешь свой код — впиши его в поле «свой код», страница сначала проверит в базе, не занят ли он.

2

Хранилище — твоя база Supabase

Пара «код → ссылка» лежит в таблице links. Запись идёт через публичный anon-ключ, а безопасность держит замок RLS: миру разрешено только читать и добавлять, менять и удалять — никому. Поэтому чужую ссылку не подменят и не снесут.

-- политики, которые ты уже выполнил в SQL Editor
create policy "все читают"  on links for select using (true);
create policy "все создают" on links for insert with check (true);
-- update/delete намеренно не открыты
3

Переход и счётчик кликов

Открываешь …/#ab3x → страница дёргает базу по коду, находит ссылку и делает location.replace(…). Параллельно вызывается функция bump_clicks — она прибавляет единицу к счётчику. Счётчик общий: тикает у всех, кто переходит.

-- «форточка» для инкремента (обходит закрытый update)
create function bump_clicks(p_code text)
returns void language sql security definer as $$
  update links set clicks = clicks + 1 where code = p_code;
$$;
4

«Твои» ссылки без аккаунта

Аккаунтов тут нет, но список «что я сокращал» страница помнит: при создании она кладёт код в localStorage этого браузера (массив myCodes). История = пересечение твоих кодов и базы. Зайдёшь с другого устройства — история будет пустая, но сами ссылки всё равно откроются: редиректу владелец не нужен.

02 /

Своя ссылка — свой домен

Чтобы сокращённые ссылки выглядели как korche.рф/promo, а не …github.io/ror/#promo, нужен короткий домен. База уже подключена — останется только прикрутить имя.

1

Купи короткий домен

У регистраторов (reg.ru, ru-center, Cloudflare, Namecheap). Зоны .site и .click бывают от ~100 ₽/год, .ru — около 200–300 ₽/год. Ищи короткое имя: korche, krch, tuda.

2

Привяжи его к хостингу

В настройках домена пропиши DNS-записи, которые покажет GitHub Pages / Netlify / Cloudflare. Подожди 5–30 минут — и твоя страница открывается по своему имени. Код менять не придётся.

3

Собери ссылку мечты

Примерь свой будущий адрес — выбери зону:

https://korche/promo
03 /

Вопросы

Ссылки теперь работают у других людей?

Да — это и есть причина подключить базу. Короткая ссылка ищет адрес в общей таблице, а не в твоём браузере, поэтому откроется с любого устройства. Проверь: скинь себе ссылку и открой её в режиме инкогнито — должен сработать переход.

Что значит чип «демо-режим» в шапке?

Что в коде не заполнены две строчки с ключами Supabase — и страница честно ушла в запасной режим (ссылки живут только в браузере). Вставь Project URL и anon public key в верх скрипта, перезалей файл — чип позеленеет в «база онлайн».

Кнопка «убрать из списка» удаляет ссылку из базы?

Нет — и это намеренно. Замок RLS закрыт на удаление, чтобы никто (и скрипт тоже) не мог снести чужое или твоё по ошибке. Кнопка лишь убирает код из твоего локального списка — ссылка перестаёт светиться в истории у этого браузера, но сама продолжает работать у всех, кому ты её дал.

А если кто-то наспамит в мою таблицу?

Теоретически создать строку может любой (иначе и ты не смог бы). На бесплатном тарифе Supabase места хватает с головой, а если станет актуально — добавим простую защиту: капчу или ограничение «не больше N ссылок в минуту с одного адреса». Это отдельная маленькая докрутка на вырост, не сегодня.

Сколько это стоит?

Код, GitHub Pages и Supabase (до 500 МБ и 50 000 активных строк) — бесплатно. Домен — по желанию, от ~100 ₽/год. Рекламы нет и не будет: это твоя страница и твоя база.
